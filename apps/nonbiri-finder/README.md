# ☕ のんびりさがし（nonbiri-finder）

「いまいる場所」や「駅名」から、**近くの観光名所・映えスポット・飲食店・ゆっくりできるカフェ**を探す Python アプリです。
40〜65 歳くらいのご夫婦・ご家族が、歩ける範囲で「のんびりできる場所」を見つけることを目指して作りました。

- 文字とボタンが大きい、3 ステップだけの画面
- 「ゆっくり歩いて 約◯分」「北東の方向」といった、感覚でわかる表示
- バリアフリー・禁煙・テラス席・個人店・トイレ・駐車場などから計算した **「のんびり度」（★1〜5）**
- 気になった場所をためておく **「行きたいリスト」**（文章でコピーして LINE などで共有できます）
- 追加のソフトを入れる必要なし。**Python だけで動きます**。地図データは無料の OpenStreetMap を使い、登録や鍵（API キー）も不要です。

---

## 1. 動かし方（3 分でできます）

### 用意するもの
- Python 3.8 以上（[python.org](https://www.python.org/downloads/) から入れられます。Windows の場合、インストール時に「Add python.exe to PATH」にチェック）
- インターネット接続（地図データを取りに行くため）

### 起動
黒い画面（Windows なら「コマンドプロンプト」、Mac なら「ターミナル」）で、このフォルダに移動して次を実行します。

```bash
cd apps/nonbiri-finder
python start.py
```

ブラウザが自動で開き、`http://localhost:8765/` に画面が出ます。
開かないときは、ブラウザのアドレス欄にその住所を手で入れてください。

終わるときは、黒い画面で **Ctrl キーを押しながら C** を押します。

### まずは見本データで試したい（ネットなしでも OK）
```bash
python start.py --demo
```
「（デモ）」と付いた架空のお店や名所が表示されます。画面の操作感を確かめる用です。

## 2. 画面の使い方

1. **どこから探しますか？**
   「📍 いまいる場所をつかう」を押す（位置情報の許可を求められたら「許可」）。
   または、駅名・地名を入れて「🔍 探す」。
2. **なにを探しますか？**
   ☕ ゆっくりカフェ／🍽️ 飲食店／📸 映えスポット／⛩️ 観光名所／♨️ 公園・温泉でひと休み を押して選びます。
3. **どのくらい歩けますか？**
   「ゆっくり 5 分」「10 分」「20 分」「車・バスで」から選びます。

結果は近い順に並びます。「のんびり度順」「有名どころ優先」に並び替えもできます。
各カードの「🧭 行き方（地図アプリ）」を押すと、スマホなら Google マップが開いて徒歩の道順が出ます。

右上の「文字の大きさ」で **標準／大／特大** に切り替えられます（次回も覚えています）。

## 3. 黒い画面（コマンド）だけで使う

ブラウザを使わず、文字だけで結果を見ることもできます。

```bash
# 駅名から（半径 700m・観光／映え／飲食／カフェ）
python -m nonbiri_finder search --place 金沢駅

# IP アドレスからおおよその現在地で、カフェと飲食店だけ、半径 500m
python -m nonbiri_finder search --here --cat cafe,food --radius 500

# 緯度・経度を直接指定して、のんびり度順
python -m nonbiri_finder search --latlon 36.578,136.647 --sort relax

# 見本データで試す／結果を JSON で出す（別のプログラムに渡すとき）
python -m nonbiri_finder search --demo --json

# 探せる種類の一覧
python -m nonbiri_finder categories
```

| オプション | 意味 |
|---|---|
| `--place 駅名` | 駅名・地名・住所から探す |
| `--latlon 緯度,経度` | 座標から探す |
| `--here` | IP アドレスからおおよその現在地（市区町村くらいの精度） |
| `--radius 700` | 半径（メートル）。100〜5000 |
| `--cat cafe,food` | 種類。`cafe` `food` `photo` `sightseeing` `rest` |
| `--sort distance` | `distance`=近い順、`relax`=のんびり度順、`famous`=有名どころ優先 |
| `--limit 30` | 表示件数 |
| `--demo` | 見本データ（ネット不要） |
| `--json` | JSON で出力 |

## 4. しくみ（むずかしい言葉の説明つき）

| ことば | 読み方 | やさしい説明 |
|---|---|---|
| OpenStreetMap | オープンストリートマップ | 世界中の人が作っている無料の地図データ。略して OSM。 |
| Overpass API | オーバーパス エーピーアイ | OSM の中から「この辺のカフェを全部ください」と頼める窓口（サーバー）。無料・鍵なし。 |
| Nominatim | ノミナティム | 「金沢駅」と言うと緯度・経度を教えてくれる OSM の地名検索。 |
| Geolocation（位置情報） | ジオロケーション | スマホやパソコンが自分の場所を教えてくれる機能。ブラウザが「許可しますか？」と聞いてきます。 |
| API キー | エーピーアイ キー | 有料サービスを使うときの「会員番号」。このアプリでは **不要** です。 |
| localhost | ローカルホスト | 「自分のパソコンの中」という意味の住所。外からは見えません。 |
| タグ | — | 地図データに付いた札。例：`amenity=cafe`（カフェ）、`wheelchair=yes`（車いす OK）。 |

### のんびり度の計算
地図データに登録されている札（タグ）を数えて ★ にしています。あくまで**目安**です。

| 加点される条件 | 対象 |
|---|---|
| 車いす OK（バリアフリー） | すべて |
| 禁煙・分煙 | すべて |
| テラス席 | カフェ・飲食店 |
| 個人店（チェーン店の札がない） | カフェ・飲食店 |
| ベンチあり | 名所・映え・公園 |
| トイレあり | すべて |
| 駐車場あり | すべて |
| Wikipedia に載っている（有名） | 名所・映え・公園 |

登録されていない情報は数えられないので、★が少なくても良いお店はたくさんあります。「個人店」はチェーン店の札が付いていないという意味で、本当に個人経営かどうかは地図データ次第です。

### 徒歩の分数
直線距離を 1.3 倍して道のりの目安にし、**時速 4km（1 分に約 67m）** のゆっくりペースで計算しています。一般の「80m＝1 分」より少し長めに出ます。

## 6. よくある質問

**Q. 「いまいる場所をつかう」を押しても現在地が出ない**
A. ブラウザの位置情報を「許可」していないか、位置情報を使えない接続（`http://192.168.…` など、自分のパソコン以外から開いた場合）です。その場合は IP アドレスからのおおよその場所に切り替わります。正確に探したいときは駅名を入れてください。

**Q. 「地図検索サーバーが混み合っています」と出る**
A. 無料の Overpass サーバーが混んでいるときに出ます。1 分ほど待ってもう一度押してください。アプリは 3 つのサーバーを順に試し、同じ条件の結果を 10 分間覚えておきます。

**Q. 地図が表示されない**
A. 地図の部品（Leaflet／リーフレット）をインターネットから読み込んでいます。社内ネットワークなどで外部サイトが制限されていると地図だけ出ませんが、一覧と「行き方」ボタンはそのまま使えます。

**Q. 検索した場所の情報はどこかに送られますか？**
A. 検索の中心となる緯度・経度は、地図データを取るために OpenStreetMap の公開サーバーに送られます。それ以外（行きたいリスト・文字サイズなど）はブラウザの中にだけ保存され、外部には送られません。

**Q. 家族のスマホからも使いたい**
A. `python start.py --host 0.0.0.0` で起動し、同じ Wi-Fi のスマホから `http://（パソコンの IP アドレス）:8765/` を開きます。この場合、ブラウザの位置情報は使えないので、駅名検索をお使いください。

## 8. スマホでそのまま使える「ブラウザ版」（Python 不要）

`web/index.html` は、Python を使わずブラウザだけで動く版です。中身の計算（カテゴリ分け・のんびり度・徒歩分）は Python 版と同じで、`python start.py` で開く画面もこの同じファイルです（その場合の検索は Python 側で行います）。

画面の機能:
- 出発地（いまいる場所 or 駅名）と、行きたい場所（目的地・任意）を分けて入力。目的地のまわり／出発地のまわりを切り替えて探せます
- 「🧭 出発地 → 目的地 の行き方」と、各スポットへの徒歩の行き方（Google マップ）
- 地図のピンは一覧と同じ絵文字（公園 🌳・温泉 ♨️ は別マーク）。地図を画面上部に固定できます
- **パソコン（画面幅 900px 以上）では立体（3D）地図**。建物の高さと地形の起伏が表示され、「🏔 立体 3D／🗺 平面 2D」で切り替え、「⟲ 北を上に」で向きを戻せます。右ボタンのドラッグ（または Ctrl＋ドラッグ）で回転・傾き。地図は MapLibre GL（無料・鍵不要）、地図データは OpenFreeMap（OpenMapTiles）、標高は AWS Terrain Tiles を使用。スマホでは従来の平面地図（Leaflet）のままです
- 店名を押すと、公式サイト → Instagram → Facebook → X → Wikipedia → Google 検索 の順で見つかった情報元へ
- 飲食店・カフェには「⭐ 食べログで見る」（食べログの検索結果を開きます。評価そのものは食べログが外部提供していないため表示できません）

- **使い方**: `web/index.html` を https のサーバー（GitHub Pages など）に置き、スマホのブラウザで開きます。位置情報（GPS）と地図が使えます。
  ※ パソコンでファイルを直接開く（`file://`）と、位置情報と地図データの取得が制限されることがあります。
- **見本データ**: 画面いちばん下の「見本データで試す」にチェックを入れると、ネットなしで動作を確認できます。
- 地図データの取得先は Python 版と同じ Overpass API / Nominatim（無料・鍵不要）です。短時間に何度も検索しないようお願いします（同じ条件は 10 分間覚えています）。
