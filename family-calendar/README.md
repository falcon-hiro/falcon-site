# あいてる？ — 家族の空き時間カレンダー

夫婦・家族など**少人数**向けの、空き時間を見つけるアプリです。
みんなの Google カレンダーを読んで「**全員が空いている時間**」を一覧にし、
そのまま「散歩」「デート」「待ち合わせ」などの予定を作って家族を招待できます。

- 公開場所：`https://az-falcon.com/family-calendar/`（main ブランチに入ると公開されます）
- 構成：`family-calendar/index.html` の1ファイルだけ（サーバー不要・無料）
- データ：予定はどこにも保存しません。ブラウザから直接 Google に読みに行きます。
  設定（クライアントID・メンバー）だけが、その端末のブラウザの中に保存されます。
- 検索エンジンには載らない設定（noindex）にしています。

> **Python 版もあります**：`python/` フォルダ（`python app.py` で自分のパソコンで動かす版）。
> 使い方は `python/README.md` を見てください。どちらも同じ機能で、違いは次のとおりです。
>
> | | ウェブ版（このフォルダ） | Python 版（`python/`） |
> |---|---|---|
> | 動く場所 | サイト上（スマホからも使える） | 自分のパソコン |
> | インストール | 不要 | Python と部品のインストールが必要 |
> | Google 側の登録 | 「ウェブ アプリケーション」＋サイトのアドレス登録 | 「デスクトップ アプリ」だけ（アドレス登録は不要） |
> | 向いている人 | すぐ使いたい・スマホで使いたい | 中身を Python で読みたい・直したい |

## できること

| 機能 | 説明 |
|---|---|
| みんなの空き時間 | 今日から 7〜28 日分を、1日ずつ「だれがいつ埋まっているか」の帯で表示。全員が空いている時間を緑で表示します。 |
| 何をする？ | 散歩（1時間）、お茶、ごはん、デート（3時間）、待ち合わせ（30分）を選ぶと、その長さ以上の空きだけに絞れます。 |
| 時間帯・週末 | 「7時〜22時」のように見る時間帯を変えたり、「週末・祝日だけ」に絞れます（日本の祝日に対応）。 |
| 予定を作る | 緑の空き時間を押すと、タイトル・場所・メモを入れて Google カレンダーに登録。家族に招待メールが届きます。 |
| 文章で送る | 「10/12(日) 13:00〜15:00 🚶 散歩 …」という文章を作って LINE などに貼れます。 |
| 家族に設定を送る | 共有リンクを家族に送ると、相手のスマホでも同じ設定ですぐ使えます。 |

## はじめかた（最初の1回だけ・パソコン推奨）

### ことばの説明

- **クライアントID**（Client ID／クライアント アイディー）：Google がこのアプリに発行する「名札」のような長い文字列です。
- **OAuth**（オーオース）：「このアプリに、わたしのカレンダーを見る許可をあげる」仕組み。パスワードは渡しません。
- **API**（エーピーアイ）：アプリ同士が会話する窓口。「Google Calendar API を有効にする」＝カレンダーの窓口を開ける、という意味です。
- **承認済みの JavaScript 生成元**（Authorized JavaScript origins／オーソライズド ジャバスクリプト オリジンズ）：「このアドレスのサイトからなら使ってよい」という許可リストです。

### 1. Google にアプリを登録して、クライアントIDをもらう（無料・10分ほど）

1. <https://console.cloud.google.com/> を開き、Google アカウントでログインします。
2. 上の「プロジェクトを選択」→「新しいプロジェクト」→ 名前は自由（例：`aiteru`）→ 作成。
3. 左メニュー「APIとサービス」→「ライブラリ」→ `Google Calendar API` を検索 →「有効にする」。
4. 「OAuth 同意画面」（新しい画面では「Google Auth Platform」→「ブランディング」「対象」）を開きます。
   - ユーザーの種類：**外部**
   - アプリ名：自由（例：あいてる？）、ユーザーサポートメール・デベロッパー連絡先：自分のメール
   - **テストユーザー**（「対象」の中）に、**自分と家族の Gmail アドレス**を追加します。
     ここに入っていない人はログインできません。
5. 「認証情報」→「認証情報を作成」→「**OAuth クライアント ID**」
   - アプリケーションの種類：**ウェブ アプリケーション**
   - 名前：自由
   - **承認済みの JavaScript 生成元**：`https://az-falcon.com` を追加
     （別の場所で公開する場合はそのアドレス。`http://localhost:8000` のように試す場合はそれも追加）
   - 「承認済みのリダイレクト URI」は空のままで大丈夫です。
   - 「作成」を押すと **クライアント ID**（`〜.apps.googleusercontent.com`）が表示されるのでコピーします。
6. アプリを開き、右上の「⚙ 設定」→「1. Google のクライアントID」に貼り付け →「保存する」。

> 「公開ステータス：テスト」のままで使えます。「アプリを公開」する必要はありません。
> ログイン時に「このアプリは Google で確認されていません」と出たら、「続行」で進めます（自分で作ったアプリなので問題ありません）。

### 2. 家族を登録する

「⚙ 設定」→「2. 家族メンバー」に、名前と **Google のメールアドレス**を入れます。
自分は、ログインすると自動で登録されます。

### 3. 家族に、カレンダーを共有してもらう

Google は、他の人の空き状況を**勝手には見せません**。家族（例：妻）に、次の操作を1回してもらいます。

1. パソコンで <https://calendar.google.com/> を開く → 右上の歯車 →「設定」
2. 左の「マイカレンダーの設定」で自分の名前のカレンダーを選ぶ
3. 「特定のユーザーまたはグループと共有する」→「ユーザーやグループを追加」
4. あなたのメールアドレスを入れ、権限は「**予定の時間枠のみを表示（詳細は非表示）**」→「送信」

これで、家族の予定の**中身は見えないまま**、「空いている／埋まっている」だけが分かります。
（「すべての予定の詳細を表示」で共有してもらうと、帯を押したときに予定の名前も出ます）

家族側も同じアプリであなたの空きを見たい場合は、あなたも同じ手順で家族に共有してください。

### 4. ログインして使う

「Google でログイン」→ アカウントを選ぶ → 「続行」→ 「カレンダーの表示」を許可。
最初に「予定を作る」を押したときだけ、追加で「予定の編集」の許可を聞かれます。

### 5. 家族のスマホでも使う

「⚙ 設定」→「共有リンクをコピー」→ LINE などで家族に送ります。
家族がそのリンクを開いて「取り込む」→ 自分の Google でログインすれば完了です。

## よくあるつまずき

| 症状 | 原因と対処 |
|---|---|
| ログイン画面に「エラー 400: origin_mismatch」や「redirect_uri_mismatch」 | 「承認済みの JavaScript 生成元」にこのサイトのアドレス（`https://az-falcon.com`）が入っていません。追加して数分待ってから再読み込み。 |
| 「アクセスをブロック：〜はGoogleの審査を完了していません」 | 「テストユーザー」にそのメールアドレスが入っていません。追加してください。 |
| 「〇〇さんの予定が見られません」と出る | 家族からのカレンダー共有がまだです（上の手順3）。メールアドレスの打ち間違いも確認。 |
| ポップアップが開かない | ブラウザのポップアップブロックを許可してから、もう一度ボタンを押してください。 |
| 1時間ほどでログインが切れる | 仕様です（安全のため）。「もう一度ログイン」を押すだけで続きが見られます。 |
| 自分のパソコンで試したい | `index.html` をダブルクリック（`file://`）では Google ログインが動きません。フォルダで `python3 -m http.server 8000` を実行し `http://localhost:8000/family-calendar/` を開き、生成元に `http://localhost:8000` を追加してください。 |

## プライバシーとしくみ

- 使っている Google の仕組み：Google Identity Services（ログイン）と Google Calendar API（`freeBusy`＝空き状況、`events`＝予定）。
- 読み取りの許可（`calendar.readonly`）でログインし、予定を登録するときだけ編集の許可（`calendar.events`）を追加で求めます。
- ログインの「鍵」（アクセストークン）はブラウザのタブを閉じると消えます。クライアントIDは秘密情報ではありません（ブラウザ用の公開 ID です）。
