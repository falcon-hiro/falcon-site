# あいてる？（Python 版）— 家族の空き時間カレンダー

夫婦・家族など**少人数**向けの、空き時間を見つけるアプリの **Python 版**です。
自分のパソコンで `python app.py` と打つと動き、ブラウザで使います。
みんなの Google カレンダーを読んで「**全員が空いている時間**」を一覧にし、
そのまま「散歩」「デート」「待ち合わせ」などの予定を作って家族を招待できます。

- 動く場所：あなたのパソコンの中だけ（外部のサーバーは使いません。無料）
- 予定のデータ：どこにも保存しません。Google から読んで画面に出すだけです
- 保存されるもの：設定（家族のメールアドレスなど）と、ログインの「鍵」だけ。どちらもこのフォルダの中です

> 同じアプリの **ウェブ版**（インストール不要・スマホから使える）は、ひとつ上のフォルダ `family-calendar/index.html` にあります。
> Python 版は「パソコンで動かしたい」「中身を Python で読みたい・直したい」人向けです。

## ファイルの説明

| ファイル | 役割 |
|---|---|
| `app.py` | 本体。画面の表示と Google との通信をすべて行います（日本語のコメント付き） |
| `templates/*.html` | 画面の見た目のひな形（トップ、予定を作る、設定、手順） |
| `static/style.css` | 画面のデザイン |
| `requirements.txt` | 必要な部品（ライブラリ）の一覧 |
| `run.bat` / `run.sh` | ダブルクリック（Windows）／ターミナル（Mac）で起動するための台本 |
| `credentials.json` | **あなたが Google から取ってきて置くファイル**（名札）。公開しないこと |
| `token.json` | ログイン後に自動で作られる「鍵」。公開しないこと |
| `settings.json` | 家族メンバーなどの設定。自動で作られます |

## ことばの説明

- **Python**（パイソン）：プログラミング言語のひとつ。このアプリの本体は Python で書かれています。
- **Flask**（フラスク）：Python でウェブ画面を作るための部品。`pip install` で入れます。
- **pip**（ピップ）：Python の部品を取ってくる道具。「`pip install -r requirements.txt`」＝一覧にある部品を全部入れる。
- **venv**（ブイエンブ／仮想環境）：このアプリ専用の部品置き場。ほかの Python の環境を汚さないための箱です。`run.bat`／`run.sh` が自動で作ります。
- **credentials.json**（クレデンシャルズ）：Google がこのアプリに発行する「名札」のファイル。
- **OAuth**（オーオース）：「このアプリに、わたしのカレンダーを見る許可をあげる」仕組み。パスワードは渡しません。
- **API**（エーピーアイ）：アプリ同士が会話するための窓口。
- **localhost / 127.0.0.1**（ローカルホスト）：「自分のパソコン自身」を指すアドレスです。

## はじめかた（最初の1回だけ）

### 0. Python を入れる（入っていない場合）

- Windows：<https://www.python.org/downloads/> から **3.9 以上**を入れます。インストール画面で「**Add python.exe to PATH**」に必ずチェック。
- Mac：ターミナルで `python3 --version` と打って 3.9 以上なら、そのまま使えます。

### 1. Google にアプリを登録して、credentials.json をもらう（無料・10分ほど）

1. <https://console.cloud.google.com/> を開き、Google アカウントでログイン。
2. 上の「プロジェクトを選択」→「新しいプロジェクト」→ 名前は自由（例：`aiteru`）→ 作成。
3. 左メニュー「APIとサービス」→「ライブラリ」→ `Google Calendar API` を検索 →「有効にする」。
4. 「OAuth 同意画面」（新しい画面では「Google Auth Platform」→「ブランディング」「対象」）
   - ユーザーの種類：**外部**
   - アプリ名：自由（例：あいてる？）、サポートメール・連絡先：自分のメール
   - **テストユーザー**に、**自分と家族の Gmail アドレス**を追加します（入っていない人はログインできません）。
5. 「認証情報」→「認証情報を作成」→「**OAuth クライアント ID**」
   - アプリケーションの種類：**デスクトップ アプリ**（ウェブ版と違い、アドレスの登録は不要です）
   - 名前：自由 → 「作成」
6. できた行の右端にある「ダウンロード」（JSON）を押し、ファイル名を **`credentials.json`** に変えて、`app.py` と同じフォルダに置きます。

> 「公開ステータス：テスト」のままで使えます。「アプリを公開」する必要はありません。

### 2. 起動する

- Windows：`run.bat` をダブルクリック（初回は部品のインストールで1〜2分かかります）
- Mac：ターミナルでこのフォルダに移動して `sh run.sh`
- 手で動かす場合：

```
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt      （Mac は .venv/bin/pip）
.venv\Scripts\python app.py                         （Mac は .venv/bin/python）
```

黒い画面に「http://127.0.0.1:8080/ を開いてください」と出たら、ブラウザでそのアドレスを開きます。
終わるときは黒い画面で **Ctrl + C** を押します。

### 3. 家族を登録する

画面右上の「⚙」→「家族メンバー」に、名前と **Google のメールアドレス**を入れて保存。
自分は、ログインすると自動で「わたし」として登録されます。

### 4. 家族に、カレンダーを共有してもらう

Google は、他の人の空き状況を**勝手には見せません**。家族（例：妻）に次の操作を1回してもらいます。

1. パソコンで <https://calendar.google.com/> を開く → 右上の歯車 →「設定」
2. 左の「マイカレンダーの設定」で自分の名前のカレンダーを選ぶ
3. 「特定のユーザーまたはグループと共有する」→「ユーザーやグループを追加」
4. あなたのメールアドレスを入れ、権限は「**予定の時間枠のみを表示（詳細は非表示）**」→「送信」

これで、予定の**中身は見えないまま**、「空いている／埋まっている」だけが分かります。

### 5. ログインして使う

「Google でログイン」→ Google の画面が開く → アカウントを選ぶ →
「このアプリは Google で確認されていません」と出たら「続行」→ カレンダーの表示と予定の編集を許可。
終わると自動でアプリの画面に戻ります。

### 6. 家族のパソコンでも使う

このフォルダごとコピーして渡します（`credentials.json` と `settings.json` も一緒に）。
家族は自分の Google でログインします。**`token.json` はあなたの鍵なので渡さない**でください（コピーする前に消せば安全です）。

## 画面の使い方

| 場所 | 説明 |
|---|---|
| 何をする？ | 散歩・お茶・ごはん・デート・待ち合わせを押すと、その長さ以上の空きだけに絞れます |
| 最短・期間・時間帯 | 空きの最短時間、何日先まで見るか、1日のうち何時〜何時を見るか |
| 週末・祝日だけ | 土日と日本の祝日だけ表示 |
| 色の帯 | その人が埋まっている時間。マウスを乗せると時刻（詳細まで共有されていれば予定名も）が出ます |
| 緑の「みんな空き」 | 全員が空いている時間。押すと「予定を作る」画面へ |
| 予定を作る | タイトル・場所・メモを入れて「カレンダーに登録して招待」。家族に招待メールが届きます |
| 文章をコピー | 「10/12(月) 18:00〜19:00 💑 デート 📍 駅の東口 …」を LINE などに貼れます |

## よくあるつまずき

| 症状 | 原因と対処 |
|---|---|
| `python` が見つからない | Python が入っていないか、PATH が通っていません。手順 0 を見てください（Windows は `py` でも試せます） |
| 「credentials.json がまだありません」 | 手順 1 の 6 で、ファイル名と置き場所（`app.py` と同じフォルダ）を確認 |
| 「アクセスをブロック：〜は Google の審査を完了していません」 | 「テストユーザー」にそのメールアドレスが入っていません |
| 「〇〇さんの予定が見られません」 | 家族からのカレンダー共有がまだです（手順 4）。メールアドレスの打ち間違いも確認 |
| 1週間ほどでログインが切れる | 「公開ステータス：テスト」の仕様です。「Google でログイン」を押し直せば続きが使えます |
| ポート 8080 が使えない | `PORT=8090 python app.py` のように番号を変えて起動（Windows は `set PORT=8090` のあとに `python app.py`） |
| 画面が古いまま | 同じ条件なら 60 秒は Google に聞き直しません。右上の「⟳」で読み直せます |

## プライバシーとしくみ

- Google の仕組み：OAuth 2.0（ログイン）、Google Calendar API（`freeBusy`＝空き状況、`events`＝予定）。
- 求める許可：`calendar.readonly`（読む）と `calendar.events`（予定の登録・編集）。
- 通信先は Google だけです。ログインの鍵は `token.json` に保存され、「ログアウト」で消えます。
