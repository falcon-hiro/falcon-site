はじめかた（かんたん手順）

このアプリはあなたのパソコンの中だけで動き、Google カレンダーを直接読みます。予定のデータはどこにも送られません。
ことばの説明
・credentials.json（クレデンシャルズ）：Google がこのアプリに発行する「名札」のファイル。これがあると Google がアプリを見分けられます。
・OAuth（オーオース）：「このアプリに、わたしのカレンダーを見る許可をあげる」仕組み。パスワードを渡さずに許可だけ出せます。
・API（エーピーアイ）：アプリ同士が会話するための窓口。「Google Calendar API を有効にする」＝カレンダーの窓口を開ける、という意味です。
・token.json（トークン）：ログイン後に自動で作られる「鍵」。人に渡さないでください。

  1. Google にアプリを登録して credentials.json をもらう（無料・10分ほど）
    1. Google Cloud Console を開き、プロジェクトを新しく作る（名前は自由。例：aiteru）
    2. 左メニュー「APIとサービス」→「ライブラリ」で Google Calendar API を探して「有効にする」
    3. 「OAuth 同意画面」（または「Google Auth Platform」）→ ユーザーの種類は「外部」→ アプリ名と自分のメールを入力 → 「テストユーザー」に自分と家族の Gmail を追加
    4. 「認証情報」→「認証情報を作成」→「OAuth クライアント ID」→ 種類は「デスクトップ アプリ」→ 名前は自由 → 作成
    5. できた行の右端にある「ダウンロード」（JSON）を押し、ファイル名を credentials.json に変えて、app.py と同じフォルダに置く → アプリを起動し直す
  2. 家族にカレンダーを共有してもらう
    1. 家族が、パソコンで Google カレンダー を開く → 右上の歯車「設定」
    2. 左の「マイカレンダーの設定」で自分のカレンダー名を選ぶ → 「特定のユーザーまたはグループと共有する」→「ユーザーやグループを追加」
    3. あなたのメールアドレスを入れ、権限は「予定の時間枠のみを表示（詳細は非表示）」でOK（予定の中身は見えず、空き・埋まりだけ分かります）
  3. 「Google でログイン」を押す。ブラウザに Google の画面が開きます。「このアプリは Google で確認されていません」と出たら「続行」で進めます（自分で作ったアプリなので大丈夫です）。
  4. 家族のパソコンでも使う：このフォルダごとコピー（credentials.json と settings.json も一緒に）して同じように起動します。家族は自分の Google でログインします。token.json はあなたのログインの鍵なので渡さないでください。
起動したら、ブラウザで {{ app_url }} を開きます。終わるときは、黒い画面で Ctrl + C を押します。
