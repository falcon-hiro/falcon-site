はじめかた（かんたん手順）

このアプリはサーバーを持たず、あなたのブラウザから直接 Google カレンダーを読みます。予定のデータはどこにも保存されません。
ことばの説明
・クライアントID（Client ID／クライアント アイディー）：Google がこのアプリに発行する「名札」のような長い文字列。これがあると Google がアプリを見分けられます。
・OAuth（オーオース）：「このアプリに、わたしのカレンダーを見る許可をあげる」仕組み。パスワードを渡さずに許可だけ出せます。
・API（エーピーアイ）：アプリ同士が会話するための窓口。「Google Calendar API を有効にする」＝カレンダーの窓口を開ける、という意味です。
・承認済みの JavaScript 生成元（Authorized JavaScript origins／オーソライズド ジャバスクリプト オリジンズ）：「このアドレスのサイトからなら使ってよい」という許可リスト。
  1. Google にアプリを登録して「クライアントID」をもらう（無料・10分ほど・パソコン推奨）
    1. Google Cloud Console を開き、プロジェクトを新しく作る（名前は自由。例：aiteru）
    2. 左メニュー「APIとサービス」→「ライブラリ」で Google Calendar API を探して「有効にする」
    3. 「OAuth 同意画面」（または「Google Auth Platform」）→ ユーザーの種類は「外部」→ アプリ名と自分のメールを入力 → 「テストユーザー」に自分と家族の Gmail を追加
    4. 「認証情報」→「認証情報を作成」→「OAuth クライアント ID」→ 種類「ウェブ アプリケーション」→「承認済みの JavaScript 生成元」に を追加 → 作成
    5. 表示された クライアント ID（…apps.googleusercontent.com）をコピーして、このアプリの「設定」に貼る
  2. 家族にカレンダーを共有してもらう
    1. 家族が、パソコンで Google カレンダー を開く → 右上の歯車「設定」
    2. 左の「マイカレンダーの設定」で自分のカレンダー名を選ぶ → 「特定のユーザーまたはグループと共有する」→「ユーザーやグループを追加」
    3. あなたのメールアドレスを入れ、権限は「予定の時間枠のみを表示（詳細は非表示）」でOK（予定の中身は見えず、空き・埋まりだけ分かります）
  3. 「Googleでログイン」を押す。「このアプリは Google で確認されていません」と出たら「続行」で進めます（自分で作ったアプリなので大丈夫です）。
  4. 家族のスマホでも使う：設定の「共有リンクをコピー」を家族に送ると、同じ設定で使い始められます。家族はあなたのカレンダーを見るので、あなたも家族に共有してあげてください。
